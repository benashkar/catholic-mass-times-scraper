Database Views (4)

Pre-joined queries for common use cases. No stored data — just saved queries.

v_sunday_masses

All active Sunday masses with church details. The bread-and-butter query for newspaper listings. Joins: service → church → lk_state → lk_language.

v_weekly_schedule

Full weekly recurring schedule for all churches, organized by church → category → day → time. Excludes one-time events.

v_confession_times

All active confession times with relative-time support (e.g., "after 08:30 Mass").

v_church_summary

Dashboard view: each church with aggregated service counts (mass, confession, adoration, devotion, total) and serving communities.

v_bulletin_summary

State-level bulletin stats: total churches, churches with bulletins, PDFs downloaded, names extracted, avg/median unique names per church.

v_bulletin_names_detail

Full provenance for every extracted name: who, from what PDF, at what church, with split name fields for matching.

v_bulletin_church_stats

Per-church bulletin stats: total PDFs, name counts by confidence and category, earliest/latest bulletin dates.

v_bulletin_ui_names

Flat denormalized view for the UI name explorer. Filterable by state, city, church, name, confidence, category.

v_bulletin_ui_city_summary

City-level rollup for the UI sidebar: church count and name counts per city per state.
